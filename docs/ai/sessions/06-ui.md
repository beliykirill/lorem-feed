     6.1 Тема и shared/ui — feat: theme and shared ui kit

     src/shared/theme/
     - palette.ts: lightColors / darkColors с одинаковыми ключами: background,
       surface (плейсхолдер картинки), text, textSecondary, border, primary,
       onPrimary, favoriteBackground (затемнённый фон строки), star, danger.
     - tokens.ts: spacing (xs 4, sm 8, md 12, lg 16, xl 24), radius, typography
       (title 17/600, body 15, caption 13).
     - use-theme.ts: useTheme() на useColorScheme() → { isDark, colors, spacing,
       radius, typography }. Тип Theme.
     - index.ts: экспорт useTheme, Theme, lightColors, darkColors, токенов.

     src/shared/ui/
     - star-icon.tsx: StarIcon({ filled, size, color }) → Text с ★/☆, цвет по
       умолчанию colors.star, accessibilityElementsHidden +
       importantForAccessibility="no-hide-descendants" (скрыт от скринридера,
       раздел 9 п.3).
     - remote-image.tsx: RemoteImage({ uri, size, accessible? }): Image поверх
       фона surface; пока грузится — пустой фон surface (+ ActivityIndicator
       только если size >= 64); onError → fallback: фон surface и приглушённый
       символ (у 32×32 — без текста). Сброс состояния при смене uri.
     - button.tsx: Button({ title, onPress, accessibilityLabel? }) на Pressable,
       цвета primary / onPrimary, accessibilityRole="button".
     - state-view.tsx: StateView({ loading?, message?, onRetry? }) — спиннер или
       текст + Button «Retry», по центру, фон темы.
     - index.ts: экспорт всех четырёх.

     src/app/
     - providers/app-providers.tsx: NavigationContainer theme={...} — тема
       навигации собирается в app из DefaultTheme/DarkTheme + палитры (shared не
       тянет navigation). StatusBar barStyle по isDark (RN core, раздел 9 п.2).
     - hydration/ui/hydration-gate.tsx: фон colors.background, удалить
       комментарий «No theme background yet».

     6.2 PostsScreen — feat: posts screen ui

     - src/entities/post/ui/post-card.tsx (новый сегмент ui, экспорт PostCard в
       entities/post/index.ts): React.memo, примитивные пропсы id, title, body,

       title (1 строка, title) + body (numberOfLines={2}, textSecondary),
       StarIcon справа только у избранного; фон favoriteBackground у избранного;
       разделитель border. accessibilityRole="button", accessibilityLabel =

       Retry), renderItem через useCallback, keyExtractor вынести на уровень
       модуля, contentContainerStyle={{ paddingBottom: insets.bottom }}, фон

       не так.
